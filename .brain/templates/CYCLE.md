# CYCLE — {{PROJECT}}

For a project that repeats: an event each month, a release each sprint, a
report each quarter.

**A routine cycle should need no assistant.** If a step here needs judgement
every time, it is not a checklist step yet — either script it or write down
the rule that decides it. Every step moved from judgement to checklist is a
step that stops costing tokens and stops going wrong.

- [ ] Anything time-bound from last cycle retired

## While it runs

- [ ] Owners edit the source directly; no code change for content
- [ ] Health check green
- [ ] New material appears only when its status says it is ready

## When it closes

- [ ] Archive what is time-bound
- [ ] Record anything that went wrong in `docs/JOURNAL.md`
- [ ] If the lesson is general, promote it to the brain
