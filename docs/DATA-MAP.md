# Data map — where every piece of information lives and who reads it

The rule: **the sheet is the source of truth; the site reads it live; anything
in the repo that mirrors sheet data is a derived copy that a tool regenerates.**
This page lists every source, every reader, and every derived copy, so a change
can be traced end to end. Audited 22 Sep 2026; re-verify with
`bash .brain/tools/state.sh` before trusting any line here.

## One pipeline for event identity

Everything that names an event goes through the same functions in `main.js`:
`parseSchedule` → `mergeRawEvents` (tickets tab) → `normaliseEvent` →
`assignSlugs` → `deriveStatus` / `ticketsLive`. The calendar, the event pages
and the **link builder** all load `main.js` and call these, so:

- an event's page address (`event/?e=<slug>`) is the same everywhere;
- "tickets live" means the same thing in the calendar row, on the event page
  and in the builder's destination list;
- the builder's programme picker and the register form's checklist come from
  the same rows.

Slugs are the title, lowercased, non-letters as hyphens; a repeated title gets
its start date appended. The Python tools mirror that rule for the sitemap and
banner filenames — the one place the rule exists twice; keep them equal.

## Campaign tagging, end to end

1. The builder writes `utm_source`, `utm_medium`, `utm_campaign` and `ref`
   into the link and records it in the `Mint` tab.
2. `main.js readRef()` captures `ref` (or `utm_source/utm_campaign`) on any
   page — home, an event page — and keeps it for the visit in `sessionStorage`.
3. Every `dataLayer` event carries it: page views, clicks, calls, outbound,
   and `registration_complete`.
4. A sign-up posts it as `ref`; the bridge writes it beside the person in
   `Sources`.

## Known duplicates that are deliberate

- `NOT_PUBLIC` keyword list: `main.js` and `tools/sync-events-fallback.py`.
- Slug rule: `main.js` and the two Python tools.
- `data/questions.json` and `FLAVOURS` in `Code.gs` (question ids must match).

Change one, change the other, in the same commit.
